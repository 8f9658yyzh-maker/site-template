# 問い合わせの受け皿と管理画面

## 1. これは何か（作った理由）
ホームページの予約・相談フォームは、送信先がないと内容が届きません。
このフォルダの `gas/Code.gs` は、お客様（契約会社）ごとのGoogleスプレッドシートに貼るだけで、
次の3つを無料でできるようにする仕組みです。

1. フォームの内容をスプレッドシートに保存する
2. 届いたことをメールで知らせる
3. 管理画面（スマホで見られる一覧）で、状態（新規・対応中・完了・見送り）とメモを付ける

NOAの予約システムとは関係なく、ホームページのひな型専用です。将来、別の仕組みにつなぎたくなったら、
フォームの送信先を変えるだけで切り替えられます（`site.json` の `reserve.formAction`）。

## 2. 設置の手順（会社ごとに1回、10分ほど）
**あなたかお客様のGoogleログインが必要です。私はログインできません。**
お客様のデータは、お客様のGoogleアカウントに置くのをおすすめします（解約時にそのまま渡せるため）。

1. お客様のGoogleアカウントで、新しいスプレッドシートを作る（名前は「問い合わせ受付」など）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初から入っているコードを全部消して、`gas/Code.gs` の中身をそのまま貼り付けて保存する
4. 関数の選択欄で `setup` を選んで「実行」する。初回は権限の確認が出るので、画面の案内に沿って許可する
   - 許可するのは「スプレッドシートの利用」と「メール送信」です（通知メールを送るため）
5. 実行ログに「管理画面の合言葉」と「通知メールの送信先」が出る。**合言葉を控える**
   - 通知先を変えたいときは、Apps Scriptの「プロジェクトの設定」→「スクリプト プロパティ」の `NOTIFY_TO` を書き換える
6. 右上の「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」を選ぶ
   - 実行ユーザー：自分
   - アクセスできるユーザー：全員
   - 表示された「ウェブアプリのURL」（`.../exec` で終わる）を控える
7. `sites/<会社名>/site.json` の `reserve.formAction` にそのURLを入れて、ホームページを作り直す
8. 動作確認：フォームから自分で1件送り、(a) スプレッドシートの「受付」シートに行が増える (b) 通知メールが届く (c) 送信後にお礼のページへ移る、の3つを見る
9. 管理画面：ウェブアプリのURLの末尾に `?page=admin` を付けて開き、合言葉を入力する

コードを直したときは、「デプロイ」→「デプロイを管理」→「新しいバージョン」で更新します（更新しないと古いままです）。

## 3. 作った内容の簡単な説明（関数）
データそのものには触れず、動きだけを説明します。

| 関数 | 役割 |
|---|---|
| `setup()` | 受付シートを作り、合言葉と通知先を決める。最初に1回だけ実行 |
| `doPost()` | フォームから届いた内容を受け取り、検査して保存し、メールで知らせる |
| `doGet()` | `?page=admin` が付いたとき、管理画面を返す |
| `adminList()` / `adminUpdate()` | 管理画面から呼ばれ、一覧の取得と、状態・メモの更新をする。どちらも合言葉の確認が先 |
| `safeCell_()` | 「=」などで始まる文字が計算式として動くのを防ぐ |
| `tooMany_()` | 1分に20件を超える送信を止める（迷惑送信対策） |
| `checkKey_()` | 合言葉を確認する。5回間違えると10分間使えなくする |
| `resetAdminKey()` | 合言葉が漏れたかもしれないとき、新しくする |

使っているGoogleの機能：スプレッドシート（保存）、MailApp（メール送信）、PropertiesService（合言葉の保管）、
CacheService（回数制限）、LockService（同時に届いたときの順番待ち）、HtmlService（管理画面）。

## 4. 守っていること（安全面）
- 人が入力しない隠し欄（`website`）が埋まっていたら、保存しない
- 名前と、連絡先（メールか電話）がなければ保存しない。1項目2000文字まで
- スプレッドシートの計算式として実行される文字は、文字として保存する
- 管理画面は合言葉なしでは中身が出ない。合言葉は画面のURLに入れない
- 状態の更新は受付番号で行を特定する（行がずれても別の人の記録を書き換えない）

## 5. できないこと・分からないこと（正直に）
- **このコードは、Googleの本物の環境ではまだ動かしていません。** 私の作業環境にGoogleのログインがないためです。
  代わりに、Googleの部品を模した偽物の上で、受信・保存・拒否・合言葉・更新の21項目を確認しました（`node tests/gas-test.mjs`）。
  管理画面は、ブラウザで偽のデータを使って動作を確認しました。本物のGoogleでの初回確認は、手順2の8番で必ず行ってください
- フォームの送信は、送信後の返事を読めない方式です（別ドメインへの送信のため）。
  通信が切れたときは画面にエラーを出しますが、「届いたのに失敗と表示される」「届いていないのに成功と表示される」
  小さな可能性は残ります。重要な予約は、通知メールが届いたかで確認する運用にしてください
- メール送信には、Googleの無料枠の1日の上限があります。最新の上限値は確認していません。契約前に調べてください
- 受付番号は、行の数から作っています。受付シートの行を手で削除すると、番号が重なることがあります。削除せず、状態を「見送り」にしてください
- 個人情報が保存されます。保存場所（お客様のGoogleアカウント）と、見られる人（お客様と、共有した人）を、
  プライバシーポリシーに書いてください。保存期間の決まりは、お客様ごとに決めて、古い行は手で消します
- ウェブアプリのURLは「全員がアクセスできる」設定です。URLが分かっても、合言葉がなければ管理画面の中身は見られません
